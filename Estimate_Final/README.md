## 🛠️ **CUSTOMIZATION**

### Adding Custom SSR Items
```python
# In streamlit_app.py or via UI
def add_custom_ssr_item(code, description, unit, rate):
    conn = sqlite3.connect('construction_estimates.db')
    cursor = conn.cursor()
    cursor.execute("""
        INSERT INTO ssr_items (id, code, description, unit, rate)
        VALUES (?, ?, ?, ?, ?)
    """, (str(uuid.uuid4()), code, description, unit, rate))
    conn.commit()
    conn.close()
```

## 🔍 **TROUBLESHOOTING**

### Common Issues

**Excel Import Problems**
- Ensure .xlsx format (not .xls)
- Check file size (<50MB)
- Verify file is not corrupted
- Check for unsupported Excel features

**Performance Issues**
- Clear browser cache
- Restart application
- Check available RAM
- Optimize Excel file size

**Database Issues**
- Restart application
- Check file permissions
- Review error logs in `logs/`
- Backup and restore if needed

**Calculation Errors**
- Verify formula syntax
- Check for circular dependencies
- Review measurement types
- Check unit consistency
