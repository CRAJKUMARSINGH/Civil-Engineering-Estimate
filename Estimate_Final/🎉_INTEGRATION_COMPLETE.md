## 💡 **PRO TIPS**

### For Best Performance
- Use .xlsx format (not .xls)
- Keep files under 50MB
- Close unused browser tabs
- Clear cache periodically

### For Best Accuracy
- Use consistent Excel structure
- Name sheets clearly (e.g., "GF1_MES", "GF1_ABS")
- Include SSR codes when possible
- Review auto-linked items

### For Best Experience
- Use Chrome or Edge browser
- Enable JavaScript
- Allow pop-ups for downloads
- Use keyboard shortcuts
